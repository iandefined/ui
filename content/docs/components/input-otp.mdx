Use `InputOTP` for short verification codes that users enter or paste.

## Usage

```tsx
import {
  InputOTP,
  InputOTPGroup,
  InputOTPSeparator,
  InputOTPSlot,
} from "@/components/ui/input-otp";

<InputOTP aria-label="Verification code" maxLength={6}>
  <InputOTPGroup>
    <InputOTPSlot index={0} />
    <InputOTPSlot index={1} />
    <InputOTPSlot index={2} />
  </InputOTPGroup>
  <InputOTPSeparator />
  <InputOTPGroup>
    <InputOTPSlot index={3} />
    <InputOTPSlot index={4} />
    <InputOTPSlot index={5} />
  </InputOTPGroup>
</InputOTP>;
```

## Composition

Group slots with `InputOTPGroup` and use `InputOTPSeparator` between groups.

## Accessibility

Provide an `aria-label` or associated visible label that explains the code being requested.

## API Reference

`InputOTP` accepts [input-otp props](https://input-otp.rodz.dev/), including `value`, `onChange`, `onComplete`, `pattern`, and `pasteTransformer`.

### Props

<ApiPropsList>
  <ApiProp name="maxLength" fullType="number" required>
    Sets the required number of OTP slots.
  </ApiProp>
  <ApiProp
    name="variant"
    fullType='"bordered" | "underlined"'
    simpleType="string"
    defaultValue='"bordered"'
  >
    Sets the visual treatment for every slot.
  </ApiProp>
  <ApiProp
    name="size"
    fullType='"sm" | "default" | "lg"'
    simpleType="string"
    defaultValue='"default"'
  >
    Sets the slot size.
  </ApiProp>
  <ApiProp name="mask" fullType="boolean" defaultValue="false">
    Obscures entered characters visually.
  </ApiProp>
</ApiPropsList>

#### InputOTPSlot

<ApiPropsList>
  <ApiProp name="index" fullType="number" required>
    Sets this slot's zero-based position.
  </ApiProp>
</ApiPropsList>
