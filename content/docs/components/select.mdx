## Usage

```tsx
import {
  Select,
  SelectIcon,
  SelectItem,
  SelectItemIndicator,
  SelectItemText,
  SelectList,
  SelectPopup,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select";
```

```tsx
const items = [
  { label: "Next.js", value: "next" },
  { label: "Vite", value: "vite" },
  { label: "Astro", value: "astro" },
];

<Select items={items}>
  <SelectTrigger>
    <SelectValue placeholder="Select a framework" />
    <SelectIcon />
  </SelectTrigger>
  <SelectPopup>
    <SelectList>
      {items.map((item) => (
        <SelectItem key={item.value} value={item.value}>
          <SelectItemText>{item.label}</SelectItemText>
          <SelectItemIndicator />
        </SelectItem>
      ))}
    </SelectList>
  </SelectPopup>
</Select>;
```

Pass `items` to `Select` when `SelectValue` should resolve a selected value to its label. Without `items`, the value renders as-is. For a searchable list, use a combobox instead.

## Anatomy

```tsx
<Select>
  <SelectTrigger>
    <SelectValue />
    <SelectIcon />
  </SelectTrigger>
  <SelectPopup>
    <SelectList>
      <SelectGroup>
        <SelectGroupLabel />
        <SelectItem>
          <SelectItemText />
          <SelectItemIndicator />
        </SelectItem>
      </SelectGroup>
      <SelectSeparator />
    </SelectList>
  </SelectPopup>
</Select>
```
