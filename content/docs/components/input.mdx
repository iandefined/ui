## Installation

<CodeTabs>
  <TabsList><TabsTrigger value="cli">Command</TabsTrigger><TabsTrigger value="manual">Manual</TabsTrigger></TabsList>
  <TabsContent value="cli">

```bash
npx shadcn@latest add https://ui.iandefined.com/r/input.json
```

The CLI also installs `TextMorph` and its Calligraph and Motion dependencies for the animated controlled example.

  </TabsContent>
  <TabsContent value="manual">

<Steps>
  <Step>Install the [Text Morph](/docs/utilities/text-morph) registry dependency:</Step>

```bash
npx shadcn@latest add https://ui.iandefined.com/r/text-morph.json
```

<Step>Install the following dependencies:</Step>

```bash
npm install @base-ui/react tailwind-variants clsx tailwind-merge
```

<Step>Add the `cn` utility to `lib/utils.ts`:</Step>

```ts filename="lib/utils.ts"
import { clsx, type ClassValue } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
```

<Step>Copy the component into your project.</Step>

<ComponentSource src="src/registry/base/input.tsx" title="components/ui/input.tsx" />
</Steps>

  </TabsContent>
</CodeTabs>

## Usage

```tsx
import { Input } from "@/components/ui/input";

<Input placeholder="Enter text" />;
```
