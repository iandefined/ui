---
title: Switch
description: A draggable toggle with spring-based thumb animation.
---

Use `Switch` for an immediate on or off setting.

## Usage

```tsx
import { Switch } from "@/components/ui/switch";
```

```tsx
const [checked, setChecked] = useState(false);

<Switch
  aria-label="Enable notifications"
  checked={checked}
  onCheckedChange={setChecked}
/>;
```

## API Reference

`Switch` wraps the [Base UI Switch](https://base-ui.com/react/components/switch). Supported Base UI props pass through.

### Props

<ApiPropsList>
  <ApiProp
    name="size"
    fullType='"sm" | "default" | "lg"'
    simpleType="string"
    defaultValue='"default"'
  >
    Sets the switch size.
  </ApiProp>
  <ApiProp name="thumbTransition" fullType="Transition" simpleType="object">
    Overrides the Motion transition used for thumb movement.
  </ApiProp>
</ApiPropsList>
