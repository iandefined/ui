---
title: Button Group
description: A container that groups related buttons together with consistent styling.
---

Use `ButtonGroup` when adjacent actions belong to the same task or control.

## Preview

<ComponentPreview name="button-group/default" />

## Installation

<ComponentInstall name="button-group" />

## Usage

```tsx
import { Button } from "@/components/ui/button";
import { ButtonGroup } from "@/components/ui/button-group";

<ButtonGroup>
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>;
```

## Composition

```tsx
<ButtonGroup>
  <Button />
  <ButtonGroupSeparator orientation="vertical" />
  <ButtonGroupText>Text</ButtonGroupText>
</ButtonGroup>
```

`ButtonGroup` is a styled `div`; standard HTML props pass through.
