## API Reference

`Textarea` wraps the native `<textarea>` element. Standard textarea attributes pass through.

### Props

<ApiPropsList>
  <ApiProp
    name="size"
    fullType='"sm" | "default" | "lg" | number'
    simpleType="string | number"
    defaultValue='"default"'
  >
    Sets the textarea's padding and text size.
  </ApiProp>
</ApiPropsList>
