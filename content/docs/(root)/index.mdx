`iandefined/ui` is an open-source registry of accessible, animated UI components crafted for product engineers. Built on [Base UI](https://base-ui.com), [Tailwind CSS v4](https://tailwindcss.com), [Motion](https://motion.dev), and [TanStack Start](https://tanstack.com/start), every item is distributed through a custom [shadcn registry](https://ui.shadcn.com/docs/registry) so you copy, paste, and own your source code.

## Why iandefined/ui?

Modern web interfaces need accessible foundations, natural motion, and clean architecture without heavy framework lock-in or fragile abstraction layers.

- **Human Design, AI Compatible**: Component contracts feature predictable prop surfaces, semantic `data-slot` hooks, and machine-readable endpoints (`/llms.txt`, `/llms-full.txt`, and `/.well-known/agent-skills/index.json`). Both human engineers and AI coding assistants can generate, refactor, and reason about interface code with precision.
- **Base UI Primitives, Not Radix Legacy**: Base UI provides unstyled accessibility, native HTML attribute forwarding, and clean render-prop composition through `render` and `useRender`. This avoids the `asChild` cloning pitfalls and ref issues common to older primitive libraries.
- **Motion and Polish Built-In**: Micro-interactions, spring physics, and animated transitions are designed as core primitives rather than afterthought overlays, respecting `prefers-reduced-motion` across every animated component.
- **Full Code Ownership**: Components install directly into your project via the `shadcn` CLI. There are no runtime package dependencies on a proprietary UI library, no theme lock-in, and no closed-source black boxes.

## Component Ecosystem

The registry is organized across four functional layers:

- **Core UI**: Foundational interactive primitives including `Button`, `Badge`, `Card`, `Checkbox`, `Switch`, `Slider`, `Radio Group`, `Tooltip`, `Popover`, `Select`, `Dropdown Menu`, `Tabs`, `Accordion`, and `Breadcrumbs`.
- **Form System**: Integrated form composition pairing native `<form>` semantics and TanStack Form workflows with `Form`, `Field`, `Fieldset`, `Input`, `Textarea`, `Number Field`, `Input OTP`, `Input Group`, `Combobox`, and `Autocomplete`.
- **Blocks**: Multi-file, production-ready application layouts such as `Sidebar 01` (located under `src/registry/base/blocks/<category>/<number>/`) that demonstrate complete compositions with dashboard routing, navigation state, and responsive behavior.
- **Motion Utilities**: Standalone styling and animation primitives including `Hitbox` for accessible touch targets, `IconSwap` for stateful icon transitions, and `TextMorph` for fluid text animations.

## Quick Start

Install individual components into your project using the official `shadcn` CLI:

```bash
npx shadcn@latest add https://ui.iandefined.com/r/button.json
```

Or install complete multi-file blocks:

```bash
npx shadcn@latest add https://ui.iandefined.com/r/sidebar-01.json
```

## AI Coding Integration

`iandefined/ui` provides dedicated, build-time static endpoints for AI coding agents and developer tooling:

- [`/llms.txt`](/llms.txt): Lightweight sitemap and index designed for fast retrieval.
- [`/llms-full.txt`](/llms-full.txt): Complete, concatenated documentation text for context injection.
- [`/r/registry.json`](/r/registry.json): Standard shadcn registry manifest describing all public components, dependencies, and file targets.
