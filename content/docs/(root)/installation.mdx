## Prerequisites

Components are distributed through the [shadcn registry](https://ui.shadcn.com/docs/registry) format. Before installing a component, make sure your project has:

- React
- Tailwind CSS v4
- `tw-animate-css` (for animation utilities)
- shadcn/ui initialized
- a `components` alias that resolves to your app's component directory

For a new project, initialize shadcn first:

```bash
npx shadcn@latest init
```

Initialization installs the [`cn`](https://github.com/shadcn-ui/cn) package and
creates `lib/utils.ts` with a compatibility re-export:

```ts
export { cn } from "cn";
```

Install `tw-animate-css`:

```bash
npm install tw-animate-css
```

For an existing project, migrate the old `clsx` and `tailwind-merge` helper
with:

```bash
npx shadcn@latest migrate cn
```

### Theme Setup

Components rely on OKLCH color variables and an `@theme inline` definition. Copy the required CSS variables from the [Theming Guide](/docs/theming) into your `globals.css` file so all components render with matching colors, borders, and radius scales.

### Configure Registry Alias (Optional)

You can add this registry to `components.json` to install components with `@iandefined/<component>` shorthand:

```json title="components.json"
{
  "registries": {
    "@iandefined": "https://ui.iandefined.com/r"
  }
}
```

Then install any component using the registry namespace:

```bash
npx shadcn@latest add @iandefined/button
```

## Adding components

### CLI

Install the Button component directly by registry URL:

```bash
npx shadcn@latest add https://ui.iandefined.com/r/button.json
```

The CLI copies the component source into your project and installs the npm dependencies declared by the registry item.

Every component that uses `cn` declares the package in its registry metadata, so
the CLI installs it automatically. If you install a component manually, add
`cn` to your project with your package manager.

Then import it from the target path:

```tsx
import { Button } from "@/components/ui/button";

export function Example() {
  return <Button variant="outline">Button</Button>;
}
```

### Manual

Copy component source from the component docs via the Manual tab. Manual installation is useful when you want to review the source before adding it to your project.

### Registry index

The registry index is available at:

```bash
https://ui.iandefined.com/r/registry.json
```

Use the index to inspect available components. Install individual components with their `/r/<component>.json` URL.
